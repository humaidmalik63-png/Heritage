# Visual Heritage Recognition and Grounded Cultural Discovery Platform

## Overview
A modular, reproducible system for visual heritage recognition using image embeddings, vector retrieval, and grounded RAG.

## Architecture
Image → Embedding → Vector Retrieval → Confidence/Unknown → Evidence Retrieval → Grounded RAG → API → Frontend

## Stack
- Frontend: Next.js/TypeScript
- Backend: FastAPI/Python
- ML: PyTorch/HuggingFace
- Vector Store: FAISS
- Database: PostgreSQL
- Containerization: Docker

## Phase 1 Foundation
This phase establishes the project structure, documentation, and scaffolding without implementing ML models, downloading datasets, or building the full application.
