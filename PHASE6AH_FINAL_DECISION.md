3. **Red Fort: no independent image-level provenance evidence** — Beyond the builder's enumeration of 3 images in `data/raw/red_fort/`, no independent provenance evidence exists for which specific images were embedded.

4. **Candidate index covers only 18 of 446 catalogue sites** — 428 non-candidate sites are expected orphans (have metadata, but are outside the candidate build scope). This is by design — the candidate index is a focused build, not a full replacement.

5. **Two pytest tests fail against active mapping but pass against candidate** — Per Phase 6U design requirements, these are expectation mismatches that should not be accommodated in the current mapping format. The tests validate candidate-specific conventions.
