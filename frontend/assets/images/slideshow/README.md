# New Seven Wonders of the World — Cinematic Background Slideshow Assets

This directory contains the seven high-resolution landscape photographs of the **New Seven Wonders of the World** used for the cinematic background slideshow on `Heritage Discovery`.

All images are authentic photographs sourced from Wikimedia Commons, verified for quality, landscape orientation (aspect ratio ≥ 1.5), and licensed for open reuse with full creator attribution.
