# One-line Python function returning "Hello, world!"

## Solution

```python
def hello_world(): return "Hello, world!"
```

This is a single physical line of Python that defines a function and returns the
required string. Calling `hello_world()` yields exactly `"Hello, world!"`.

## Why this form

- **One line, strictly.** The entire function — `def` header and body — is one
  physical line, so it satisfies the strictest reading of "one-line function"
  as well as the looser reading of "a function with a one-line body."
- **It returns, not prints.** The task asks for a function that *returns* the
  string, so the body uses `return`. A `print`-based version would not satisfy
  "returns."
- **No parameters.** The task specifies none, so the function takes no
  arguments.
- **Exact string.** `"Hello, world!"` — capital H, comma, space, lowercase `w`,
  exclamation mark, no trailing period. Verified by assertion against the task
  text.

## Verified

The line was executed and checked:

```python
def hello_world(): return "Hello, world!"
assert hello_world() == "Hello, world!"
```

Both the call and the assertion pass.

## Alternative (two-line form)

If readability is preferred over strict single-line compliance:

```python
def hello_world():
    return "Hello, world!"
```

This is semantically identical and also has a one-line body; only the `def`
line is separate. Behavior is the same.

## Assumptions

- **Function name.** The task gives no name. `hello_world` is the natural
  choice; any valid name works since the task only specifies behavior.
- **"One-line" = one physical line.** Taken as the strictest reasonable reading.
  The looser reading (one-line body) is also satisfied by the chosen form.
