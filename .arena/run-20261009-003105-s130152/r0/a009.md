# Solution

```python
def hello(): return "Hello, world!"
```

This is a single physical line. It defines a named function `hello` that returns exactly the string `"Hello, world!"` — capital H, a comma followed by a single space, lowercase "world", and an exclamation mark, with no trailing whitespace or newline.

## Why this form

A Python function body normally needs its own indented line, but Python allows a simple statement to follow the colon on the same line, so the definition stays on one line while remaining a real, named, importable `def`. A `lambda` would also be one line, but it is an anonymous expression rather than a named function, so it is a weaker match for "a Python function."

## Verify

```python
assert hello() == "Hello, world!"  # passes
```
