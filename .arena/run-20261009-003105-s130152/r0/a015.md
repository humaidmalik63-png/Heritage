# One-line "Hello, world!" function

```python
def hello_world(*args, **kwargs) -> str: return "Hello, world!"
```

## Why this line

- **One line.** The `def` and the `return` live on a single physical line.
- **It is a function.** A named, callable object created with `def`.
- **It returns the exact string.** `return "Hello, world!"` — capital `H`, comma, space, lowercase `w`, exclamation mark, no trailing whitespace or newline in the returned value. No concatenation, formatting, or `chr()` construction is used, so the output cannot drift from the literal.
- **It survives weird inputs.** `*args, **kwargs` means the function accepts zero arguments, positional arguments, or keyword arguments without raising, so no unexpected call signature can break it.

## Assumptions

- "One line" means the function definition is a single line. The surrounding text is documentation, not part of the function.
- The required string is exactly `Hello, world!`; nothing else should be returned (no newline, no extra characters).
- "Returns" means the function uses `return`, not `print`.

## Verification

```python
assert hello_world() == "Hello, world!"
assert hello_world(1, 2, x=3) == "Hello, world!"
```
