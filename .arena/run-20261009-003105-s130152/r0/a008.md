# Solution

```python
def hello_world() -> str: return "Hello, world!"
```

This is one physical line, one `def` statement, and one `return` of the exact string `"Hello, world!"` (capital H, comma, space, lowercase w, exclamation mark, no period, no trailing newline).

Call it:

```python
>>> hello_world()
'Hello, world!'
```

## Assumptions

- **Function name.** The task does not specify a name. `hello_world` is the conventional choice and can be renamed freely — the requirement is a one-line function that returns the string, not the name.
- **"Returns" means the Python `return` statement**, not `print()`. A `print` call writes to stdout and yields `None`; `return` makes the value available to the caller.

## Verification

Run this in any Python 3 interpreter:

```python
import ast
src = "def hello_world() -> str: return \"Hello, world!\""
tree = ast.parse(src)          # raises SyntaxError if invalid
assert len(src.splitlines()) == 1
assert isinstance(tree.body[0], ast.FunctionDef)
ns = {}
exec(compile(tree, "<sol>", "exec"), ns)
assert ns["hello_world"]() == "Hello, world!"
```

All four checks pass: it parses, it is one line, it is a function, and its return value is exactly `"Hello, world!"`.
