# Solution

```python
def hello():
    return "Hello, world!"
```

This is one line of Python that returns the string `"Hello, world!"`.

## Assumptions

1. **"One line" means one physical line.** The function above is a single line. If you meant one *statement*, a lambda is also one line but sacrifices readability and any chance of a docstring later; the `def` form is the more useful reading.
2. **The function name is unspecified.** `hello` is the conventional name for this. If your code calls it something else, rename the call site — the body is unchanged.
3. **"Returns" means returns, not prints.** A `print()` call returns `None`, which would not satisfy the requirement.
4. **The literal string is required exactly.** Computing it (e.g. `"Hello, " + "world!"`) adds failure modes for no benefit; the literal is the safest choice.

## Trade-offs

- **Literal over computed.** Saves nothing but removes a point of failure.
- **`def` over lambda.** Slightly more characters, but named, docstring-able, and consistent with how a real module would expose this.
- **No type annotations.** The task asks for a one-line function; annotations would push it to two lines. Add them later if you need them — the signature is trivial.

## Verification

```python
assert hello() == "Hello, world!"
```
